🎯 Purpose & Scope

AeroTrack is a real-time flight operations dashboard built as a single-page Angular 20 application. It enables operations teams to monitor 20 live international flights on an interactive world map, filter by status / route, inspect per-flight telemetry, and track KPI counts — all without a backend server (data served from a bundled JSON mock). The design goal was enterprise-grade UX with zero unnecessary abstractions: every Angular 20 primitive (Signals, toSignal, standalone components, lazy routing) is used where it genuinely simplifies the code.

⚙ FlightService State Machine

A single root-level service owns all shared state, keeping components thin and avoiding prop-drilling.

RxJS (async / stream)
filter$ — BehaviorSubject; emits on every user input
allFlights$ — HTTP GET, shareReplay(1)
filteredFlights$ — combineLatest + debounceTime(300)

Signals (synchronous / derived)
selectedFlight — writable signal, set on map click
kpis — computed() from all flights
filteredKpis — computed() from filtered flights
uniqueOrigins / Destinations — computed() for dropdowns

Bridge
toSignal(filteredFlights$) bridges the RxJS stream into the Signal graph — consumed by the map's effect().

All components use ChangeDetectionStrategy.OnPush — re-render only on signal/input change or markForCheck. The Leaflet map runs entirely outside Angular's zone (NgZone.runOutsideAngular), re-entering only on marker click via NgZone.run().

💡 Key Design Decisions

  • Signals + RxJS hybrid HTTP loading and filter debounce stay in RxJS (naturally async); selection and KPIs use Signals (synchronous derived state). toSignal() is the seam.
  • Lazy-loaded dashboard route loadComponent() on /dashboard — keeps the initial bundle minimal and enables future route-level code-splitting.
  • Leaflet outside NgZone All map DOM mutations happen off Angular's change-detection cycle, preventing unnecessary app-wide checks on every mouse/tile event.
  • MarkerCluster + canvas renderer Clusters prevent marker overlap at world zoom; preferCanvas: true reduces DOM node count from ~100 marker elements to a single canvas element.
  • Standalone components only No NgModules; every component declares its own imports. Eliminates shared-module bloat and makes tree-shaking exact.
  • Responsive dual layout FlightList renders a mat-table on wide viewports and compact cards on mobile — same component, CSS grid breakpoints switch the template.
